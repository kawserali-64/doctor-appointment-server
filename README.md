## 📌 Project Overview

DocAppoint Server is the backend of the Doctor Appointment Management System.  
It handles doctor data, appointment booking, authentication, and secure API management using JWT-based authorization.

This backend supports all core functionalities including doctor listing, booking system, and user-specific appointment management.

---

## ⚙️ Tech Stack

- Node.js
- Express.js
- MongoDB
- JWT (Authentication)
- CORS
- dotenv
